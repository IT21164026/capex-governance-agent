# capex-governance-agent

## Business Problem
Explain the operational or finance risk problem.

## Solution
Explain dashboard + analytics engine + agent workflow.

## Architecture
Raw data -> Python processing -> exception/recommendation table -> Power BI dashboard -> Streamlit agent -> approval/action log.

## Features
- Exception detection
- Risk scoring
- Root-cause explanation
- Recommended actions
- Human approval workflow
- Simulated execution log

## Tech Stack
Python, Pandas, Power BI, Streamlit, SQL-ready CSV data model.

## How to Run
1. Create virtual environment
2. pip install -r requirements.txt
3. Generate data
4. Run engine
5. Run Streamlit app
